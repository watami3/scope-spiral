01 / THE PROBLEM

解けない理由は、
「見ている範囲」にあるかもしれない。

原因を早く決めつけると見落とす。調査を広げ続けると動けない。SCOPE Spiralは、問題の捉え方そのものを点検します。

1

狭すぎる

担当者の能力だけを疑い、承認工程や制度の問題を見逃す。

2

広すぎる

すべてを調査し続け、時間もコストも増えていく。

3

固定しすぎる

新しい事実が出ても、最初の問題設定に固執する。

概念図：探索範囲は最初から固定せず、観測結果に応じて調整する。

02 / CORE THEORY

Dynamic Scope Controlとは？

探索・分析・介入の対象範囲を、事実とフィードバックに応じて意図的に維持・変更する意思決定過程。SCOPE Spiralは、それをAIとの対話で運用する仕組みです。

01

Problem Model

何を問題と捉え、どのような原因仮説を置くか。

02

Scope

どの要素を探索・分析・介入の対象に含めるか。

03

Feedback

新しい事実が入ったら、問題モデルと範囲を再評価する。

反復サイクル：Fact → Hypothesis → Orient Scope → Action → Feedback

Q1. 今の問題設定で解決できるか？

中核の仮説や前提に重大な矛盾がないか。

Q2. 次にどこを見るべきか？

探索対象を維持するか、広げるか、絞るか。

03 / FOUR OPERATIONS

思考の範囲を動かす、4つの操作。

重要なのは操作の名前ではなく、どの証拠を見て切り替えるか。Shiftは他の範囲操作と併用できます。

HOLD

維持する

現在の範囲で検証・行動が可能。何もしないこととは異なる。

EXPAND

広げる

現Scopeでは説明できない。関連要因や関係者を探索に加える。

CONTRACT

絞る

主要制約が特定領域に局在する証拠が蓄積した。

SHIFT

捉え直す

新事実と中核仮説が矛盾した。問題モデルを変更する。

注意：単に優先順位をつけることはContractではありません。またRisk Overrideは5番目の操作ではなく、重大リスクを優先するルールです。
04 / HOW IT WORKS

複雑な仕組みを、簡単な会話で。

利用者が操作名を覚える必要はありません。AIには、通常「結論・根拠・次の行動」を短く返すよう指示します。

Close / Dormant / Continueの状態判定を先に行い、必要に応じて再探索します。

1

Fact と Hypothesisを分ける

確認済みの事実と推測を混同しない。

2

重要な制約を見極める

期限、資金、権限、リスク、探索コストを確認。

3

Scopeを調整する

新しい情報に応じて操作を選ぶ。

4

行動し、結果で修正する

仮説に固執せず、反証が出たら更新する。

08 / FAQ
よくある質問
インストールに費用はかかりますか？
プロンプト自体は無料です。利用するAIサービスの料金・制限は各サービスのプランによります。
一度入れれば、すべての会話で使えますか？
必ずしもそうではありません。新しい会話では再添付・再入力が必要になる場合があります。
SCOPEの専門用語を覚える必要はありますか？
ありません。自然な言葉で問題を説明すれば、AIが必要に応じて内部でScopeを点検する設計です。
どんなAIでも同じように動きますか？
いいえ。指示追従、長文処理、ファイル添付、記憶などの仕様により結果が変わります。
理論の効果は実証されていますか？
現段階では、通常のAI利用などとの比較による定量的な優位性は確立されていません。今後の実証課題です。
どんな問題に向いていますか？
複雑で曖昧な問題、前提が変化する問題、探索範囲が広がりすぎる案件などに向いています。単純な事実確認には通常回答で十分です。
理論上の位置づけ
OODAやPDCAなどの既存手法を否定するものではありません。SCOPE Spiralは、問題モデルと探索・介入範囲の制御を明示することに焦点を当てています。独自性と有効性は今後の研究・比較検証の対象です。
